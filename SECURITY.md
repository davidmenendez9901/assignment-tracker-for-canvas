# Security Policy

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Report privately through GitHub: go to the repository's **Security** tab → **Report a vulnerability**
(https://github.com/davidmenendez9901/assignment-tracker-for-canvas/security/advisories/new).

Include steps to reproduce and the affected version. Do not include real student data. You can expect an initial response within 7 days.

## Scope

Examples of what counts as a vulnerability here:

- Any way for the extension to send data to a host other than the Canvas site the user is on.
- Any non-GET request the extension can be made to send.
- Script or HTML injection through Canvas data shown by the extension.
- Permissions broader than documented.

## Supported versions

Only the latest released version receives fixes.
